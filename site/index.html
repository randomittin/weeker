An adaptive exam-prep learning engine you run on your own machine. Point it at a certification workbook and it does the rest.

Weeker ingests a workbook PDF, extracts a reviewed concept inventory, generates original gate-verified questions and caselets, then drives an adaptive study loop toward a full-pattern mock and a score prediction. Built for India's NISM certifications; workbook-agnostic.

Pipeline

Workbook in, mastery out

The differentiator

Nothing ships unproven

Every generated question runs a chain of six independent quality gates before it can ever reach you. Each question stores its gate evidence — so mastery is replayable straight from the attempt log.

A question is rejected the moment any gate fails. Source text is never copied; correctness is confirmed by a second model family that never saw the answer.

G1 Structural Exactly 4 options, exactly 1 correct, no all/none-of-the-above, options are distinct.
G4 Originality 8-gram overlap + stem↔source cosine check — the source text is never copied.
G5 Dedup / variant Near-duplicates and thin variants of existing items are collapsed out.
G2 Grounding An LLM verifier confirms the question and key are grounded in the source concept.
G3 Blind-solve A different model family solves it blind; consensus confirms, dispute rejects.
G6 Scenario-dependence For caselets: the scenario must be load-bearing, not decorative context.

draft → G1 → G4 → G5 → G2 → G3 → G6 → banked, with evidence

Learning science

Measured ability, not vibes

Concepts are the unit of mastery. The loop estimates what you know, schedules what you'll forget, and remembers where you went wrong.

Confidence-weighted Elo

Each concept carries an Elo-style ability estimate that moves with every attempt — weighted by how confident you were.

A day-0 diagnostic seeds the estimate so the loop starts calibrated instead of cold.

FSRS-lite retention

A spaced-retention scheduler surfaces concepts just before you'd forget them, balancing new material against review.

Study time flows to weak and decaying concepts first.

Concept mastery & misconceptions

Mastery is tracked per concept, not per question — so it generalises across the whole item bank.

Wrong answers feed a misconception model that targets what to fix next.

Get started

Clone it and run weeker doctor

Pure Python. No hosted service, no account — the engine lives on your machine and the CLI and TUI are thin shells around it.

tests195 passing coverage~85% python3.11 licenseMIT gatesG1–G6
SQLAlchemy 2.0 Postgres + pgvector PyMuPDF Typer CLI Textual TUI pydantic v2
bash 
$ git clone https://github.com/randomittin/weeker && cd weeker
$ pip install -e .
$ weeker doctor            # readiness check
$ weeker ingest run         # workbook → concepts
$ weeker mock diagnose      # day-0 diagnostic, seed ability
$ weeker study run          # adaptive study loop
$ weeker mock full          # full-pattern mock + prediction
$ weeker status show        # mastery + readiness

Postgres + pgvector is the production path; the test suite runs on SQLite with no keys or Postgres needed.
